Calculator System (C++)

A menu-driven calculator application built in C++ to practice core programming concepts such as functions, arrays, pointers, recursion, dynamic memory allocation, and modular programming.

Features

Basic Operations

- Addition
- Subtraction
- Multiplication
- Division

Advanced Operations

- Power Calculation
- Factorial Calculation
- Prime Number Check

Array Operations

- Input Array
- Print Array
- Find Maximum Element
- Find Minimum Element
- Reverse Array
- Move Zeros
- Move Even Numbers
- Count Occurrences of an Element

Concepts Used

- Functions
- Arrays
- Pointers
- Dynamic Memory Allocation
- Recursion
- Header Files
- Menu-Driven Programming

Project Structure

calculator-system-cpp/
├── main.cpp

├── file.hpp
└── README.md

How to Run

g++ main.cpp calculator.cpp -o calculator
./calculator
